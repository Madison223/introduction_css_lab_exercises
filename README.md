# introduction_css_lab_exercises
This repository contains a lab assignment focused on the introduction to Cascading Style Sheets (CSS). The lab consists of 12 exercises designed to build the foundational CSS skills and core styling concepts used for web development. 

## Topics Covered

- Inline, internal, external CSS
- Selectors and properties
- colors and backgrounds
- fonts and text styling
- margins, padding, and borders
- basic layout concepts
